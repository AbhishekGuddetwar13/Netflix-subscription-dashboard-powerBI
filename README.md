# Netflix Subscription Dashboard

## Project Overview

This project presents an interactive Power BI dashboard built using Netflix subscription data. The dashboard provides insights into subscription performance, revenue generation, subscription types, renewal status, and monthly trends.

The objective of this project is to transform subscription data into actionable business insights using Power BI and Excel.

## Business Insights

### Highest Revenue Plan
Basic Subscription generated the highest revenue contribution.

### Subscriber Distribution
All subscription plans contributed nearly equal subscriber counts.

### Renewal Status Analysis
Active subscribers represented the largest customer segment.

### Monthly Trend
Revenue and subscriptions showed a declining trend from January to March.
